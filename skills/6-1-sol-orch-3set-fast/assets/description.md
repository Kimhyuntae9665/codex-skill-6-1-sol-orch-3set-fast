# 3개 세션 병렬 실행과 정보 통합

맨 위와 맨 아래 Sol은 같은 총괄입니다. 세 개 SESSION의 Sol 리더를
각각 새 채팅으로 만들고, 각 리더가 Luna 두 명과 Sol 한 명을 병렬 실행합니다.
점선 Astra는 완료된 자료에 대한 선택적 리뷰입니다. 기본 13명이며
모든 Astra 리뷰어까지 함께 존재하면 총 16명입니다.

회색 화살표는 생성·작업 지시·결과 전달입니다. 각 하위 결과는
해당 세션 리더로 돌아옵니다. 세 리더가 공통 작업 폴더의 JSON에
자기 결과를 공개하고, 파란 점선 화살표로 다른 세션 자료를 읽습니다.
총괄은 출처·버전·체크섬을 확인해 최종 통합합니다. JSON 카드는
파일 기반 공유 공간이며 추가 에이전트나 외부 서버가 아닙니다.

모든 에이전트에 Fast 설정이 필수입니다. 세 세션의 실행 용량과
파일 기반 정보 전달은 시험했으며, 실제 서버 제공 tier나 속도 향상은
이 모식도가 증명하지 않습니다. 그림의 모델 도형은 승인된 설명용
원본 glyph이며 공식 OpenAI 로고가 아닙니다.
